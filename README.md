# 🌸 Estudio · Política Exterior Colombiana

Página interactiva para estudiar los dos videos de **Déjà vu** (La Silla Vacía):

1. 🏗️ *Un duelo de titanes en los orígenes de la tecnocracia colombiana: Lauchlin Currie – Albert Hirschman*
2. 🎓 *Malcolm Deas, el oráculo de Oxford*

Incluye resúmenes por tema, personajes, líneas de tiempo, cuadro comparativo, flashcards y quices:
selección múltiple (única respuesta), verdadero/falso, completar, ¿Currie o Hirschman?, ¿Qué diría Deas?,
relacionar columnas, ordenar cronología, simulacro y repaso de errores.

Abrir `index.html` o entrar a la página de GitHub Pages del repo.
